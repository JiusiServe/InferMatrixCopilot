### `vllm_omni/model_executor/models/common/ming/audio_vae.py:349-351` — medium / other

Stochastic latent sampling in `encode_latent` under `@torch.inference_mode()`. Standard VAE inference uses the mean directly for deterministic encoding. The reparameterization trick (`mean + std * randn`) is intended for training, not inference, and makes every call non-reproducible. Consider using the mean-only path during inference (as the original code did), or gate the sampling behind an explicit flag if stochastic encoding is truly desired at inference time.

Anchored to:

```
        mean, scale = torch.chunk(h, 2, dim=1)
        std = F.softplus(scale) + 1e-4
        latent = (mean + std * torch.randn_like(mean)).transpose(1, 2)
```

Suggested:

```
        mean, scale = torch.chunk(h, 2, dim=1)
        std = F.softplus(scale) + 1e-4
        # During inference, use deterministic encoding (mean only).
        latent = mean.transpose(1, 2)
```
