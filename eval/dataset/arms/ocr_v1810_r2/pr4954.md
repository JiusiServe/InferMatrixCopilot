### `tests/helpers/assertions.py:59-61` — medium / bug

The substring check `expected_clean in transcript_clean` lacks word-boundary enforcement, which can cause false-positive matches when the expected text appears as part of a longer word (e.g., `"how"` matching inside `"somehow"`). Use a regex with `\b` word boundaries to ensure whole-word matching: `re.search(r'\b' + re.escape(expected_clean) + r'\b', transcript_clean)`. Since `preprocess_text` strips all non-word/non-whitespace characters, `\b` will reliably delineate word boundaries. Note: this also requires adding `import re` at the top of the file.

Anchored to:

```
    short_text = min(len(transcript_clean), len(expected_clean)) <= 15
    small_word_delta = len(transcript_words) <= len(expected_words) + 2
    return short_text and small_word_delta and expected_clean in transcript_clean
```

Suggested:

```
    short_text = min(len(transcript_clean), len(expected_clean)) <= 15
    small_word_delta = len(transcript_words) <= len(expected_words) + 2
    return (
        short_text
        and small_word_delta
        and bool(re.search(r"\b" + re.escape(expected_clean) + r"\b", transcript_clean))
    )
```
