### `vllm_omni/model_executor/models/moss_tts/audio_tokenizer_v2.py:947-949` — high / bug

The comment explicitly states "Use a ceil division to match that padding and avoid dropping the last (partially padded) frame", but the code uses floor division (`//`). `_flatten_channels_for_codec` pads the waveform tensor to a multiple of `downsample_rate` without updating `input_lengths`, so when `input_lengths` is not an exact multiple of `patch_size`, floor division silently drops valid output frames. This causes downstream masking in the quantizer to discard good data. Use ceil division: `(input_lengths + self.patch_size - 1) // self.patch_size`.

Anchored to:

```
        # We pad the input waveform to a multiple of `downsample_rate` before applying the encoder.
        # Use a ceil division to match that padding and avoid dropping the last (partially padded) frame.
        output_lengths = input_lengths // self.patch_size
```

Suggested:

```
        # We pad the input waveform to a multiple of `downsample_rate` before applying the encoder.
        # Use a ceil division to match that padding and avoid dropping the last (partially padded) frame.
        output_lengths = (input_lengths + self.patch_size - 1) // self.patch_size
```
