### `vllm_omni/platforms/cuda/platform.py:125-128` — medium / bug

The `except ImportError` is too narrow. A partially installed or ABI-mismatched `kernels` library can raise `OSError` or `RuntimeError` during import (e.g., from native extension loading), which would bypass this fallback and crash the startup. Use `except Exception` to match the pattern already used for the flashinfer probe at line 115, which explicitly documents this concern.

Anchored to:

```
                try:
                    importlib.import_module("kernels")
                    logger.info("Using HuggingFace kernels-backed attention backend '%s'", backend_upper)
                except ImportError:
```

Suggested:

```
                try:
                    importlib.import_module("kernels")
                    logger.info("Using HuggingFace kernels-backed attention backend '%s'", backend_upper)
                except Exception as e:
                    logger.debug("HuggingFace kernels probe failed (%s); treating as unavailable", e)
```

### `vllm_omni/diffusion/attention/backends/flash_attn_hub.py:101-103` — medium / bug

The default fallback call `get_kernel("kernels-community/flash-attn2")` at line 103 is not wrapped in a try-except. If this call also fails, the raw `get_kernel` exception propagates and the clearer `RuntimeError("Failed to load flash-attn2 kernel from HuggingFace Hub: no functions found")` on line 109 is never reached. Consider wrapping the default fallback in another try-except so the explicit RuntimeError is raised, or restructure the error handling.

Anchored to:

```
            except Exception as e2:
                logger.info("Failed to load version 2, attempting default: %s", e2)
                hub_module = get_kernel("kernels-community/flash-attn2")
```

Suggested:

```
            except Exception as e2:
                logger.info("Failed to load version 2, attempting default: %s", e2)
                try:
                    hub_module = get_kernel("kernels-community/flash-attn2")
                except Exception as e3:
                    logger.info("Failed to load default: %s", e3)
                    hub_module = None
```
