### `vllm_omni/model_executor/models/common/ming/audio_vae.py:141-142` — medium / bug

Mutating `config.num_hidden_layers = 4` corrupts the shared config object that was already passed to `self.encoder = Qwen2Model(config)` at line 131. Since HuggingFace models store `self.config` by reference, `self.encoder.config.num_hidden_layers` is now silently changed from its original value to 4. This can cause incorrect behavior in serialization, config inspection, or any code that reads the encoder's config. The previous code correctly created a separate config via `_qwen2_config({**encoder_args, "num_hidden_layers": 4})`.

Anchored to:

```
            config.num_hidden_layers = 4
            self.aggregator = Qwen2Model(config)
```

Suggested:

```
            aggregator_config = _qwen2_config({**encoder_args, "num_hidden_layers": 4})
            self.aggregator = Qwen2Model(aggregator_config)
```
