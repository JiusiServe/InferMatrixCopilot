### `vllm_omni/diffusion/attention/backends/flash_attn_hub.py:30-33` — medium / bug

When `q_len == 0` (empty query sequence), `torch.arange` is called with `step=0`, which raises `RuntimeError: step must be nonzero`. While this is unlikely in normal diffusion model inference, it could occur in edge cases (e.g., empty prompts or zero-length text conditioning). Add a guard or early return for `q_len == 0`.

Anchored to:

```
    batch_size, q_len = query.size()[:2]
    k_len = key.size(1)
    cu_seqlens_q = torch.arange(0, (batch_size + 1) * q_len, step=q_len, dtype=torch.int32, device=query.device)
    cu_seqlens_k = torch.arange(0, (batch_size + 1) * k_len, step=k_len, dtype=torch.int32, device=query.device)
```

Suggested:

```
    batch_size, q_len = query.size()[:2]
    k_len = key.size(1)
    if q_len == 0 or k_len == 0:
        return query
    cu_seqlens_q = torch.arange(0, (batch_size + 1) * q_len, step=q_len, dtype=torch.int32, device=query.device)
    cu_seqlens_k = torch.arange(0, (batch_size + 1) * k_len, step=k_len, dtype=torch.int32, device=query.device)
```
