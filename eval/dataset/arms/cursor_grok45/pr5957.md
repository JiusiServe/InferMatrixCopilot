### 1. Shared BigVGAN resolver breaks prior IndexTTS-2 local-path HF fallback

`vllm_omni/model_executor/models/indextts2/indextts2_s2mel_decoder.py:71-83`

```71:83:vllm_omni/model_executor/models/indextts2/indextts2_s2mel_decoder.py
def _resolve_bigvgan_source(model_path: str, vocoder_name: str) -> str:
    if os.path.isdir(vocoder_name):
        return vocoder_name
    local_dir = resolve_model_directory(
        model_path,
        "bigvgan",
        os.path.join("hf_cache", "bigvgan"),
    )
    if local_dir is not None:
        return local_dir
    if os.path.isdir(model_path):
        raise FileNotFoundError(f"IndexTTS BigVGAN assets are missing from local bundle {model_path!r}")
    return vocoder_name
```

**Trigger:** any local model directory (IndexTTS-2 or 2.5) without vendored `bigvgan/` / `hf_cache/bigvgan/`.  
**Before:** Stage 1 called `BigVGAN.from_pretrained("nvidia/bigvgan_v2_...")` and could fetch the public vocoder.  
**Now:** hard `FileNotFoundError` on every local directory. Confirmed in this environment.  
**Impact:** intentional for native 2.5 bundles, but this is shared `IndexTTS2S2MelDecoder` code — IndexTTS-2 local checkouts that previously worked without vendoring BigVGAN now fail at load/warmup.  
**Fix:** scope the fail-fast to IndexTTS 2.5 / native bundles (or an explicit flag), and keep HF ID / IndexTTS-2 local fallback unless docs require vendoring for both.

### 2. Bare scalar `duration_factor` is silently ignored (native speed no-ops)


**Trigger:** offline / direct Omni `additional_information` with `"duration_factor": 0.5` (scalar) instead of `[0.5]`.
