```96:99:vllm_omni/diffusion/cache/teacache/config.py

    "MiniMaxH3DiTModel": 0.17,
}
```

```420:422:vllm_omni/diffusion/data.py
    # TeaCache parameters [tea_cache only]
    # None defers to the model-specific TeaCache default (0.2 fallback).
    rel_l1_thresh: float | None = None
```

But every Omni/serve path that omits `cache_config` goes through `AsyncOmniEngine._normalize_cache_config` → `_get_default_cache_config("tea_cache")`, which **forces** `0.2`:

```853:856:vllm_omni/engine/async_omni_engine.py

            return {
                "rel_l1_thresh": 0.2,
            }
```

**Trigger:** `Omni(..., cache_backend="tea_cache")` or `vllm serve ... --cache-backend tea_cache` without `--cache-config`.  
**Effect:** `_MODEL_DEFAULT_REL_L1_THRESH` is dead on the public entry path; only direct `TeaCacheBackend(DiffusionCacheConfig())` (as in unit tests) gets `0.17`. Recipe/e2e paper over this by hard-coding `0.17`.  
**Fix:** For `tea_cache`, return `{}` / omit `rel_l1_thresh` so `None` can defer to the model map; or stop changing the shared default and set MiniMax’s `0.17` only inside `enable_minimax_h3_teacache` after the engine empty-config path stops pinning `0.2`.
