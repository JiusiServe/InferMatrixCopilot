### 3. `tests/model_executor/models/test_kv_cache_scale_mapper.py:19-38` — the mapper tests pass vacuously (P2)

```python
_SOURCE_SCALE_NAME = "layers.0.self_attn.k_proj.output_scale"
...
yield name.replace(".k_proj.output_scale", ".attn.k_scale"), weight
```

`_RecordingCacheScaleMapper` invents a rename the real mapper does not perform. Checked directly against `QuantizationConfig.get_cache_scale_mapper()`:

- `...self_attn.k_proj.k_scale` → `...self_attn.attn.k_scale` ✅
- `...self_attn.kv_scale` → `...self_attn.attn.k_scale` ✅
- `...self_attn.k_proj.output_scale` → **unchanged** ❌

The real regex set (`vllm/.../base_config.py:204-226`) covers `.kv_scale`, `.self_attn.[kv]_proj.[kv]_scale`, `.self_attn.qkv_proj.[kv]_scale`, `.mixer.*`, HYV3 forms, and a default `.{q,k,v}_scale`. There is no `output_scale` pattern. So `test_direct_custom_loaders_apply_cache_scale_mapper` exercises a name shape that never occurs, and would still pass if the production wiring in `mammoth_moda2` / `mimo_audio_llm` were placed wrongly. Use `layers.0.self_attn.k_proj.k_scale` as `_SOURCE_SCALE_NAME`, and drop the fakes in favour of the real `get_cache_scale_mapper()` on a stub quant config — that turns three vacuous assertions into a real contract check.

### 4. `vllm_omni/model_executor/models/mimo_audio/mimo_audio_llm.py:1156-1163` — kv-scale misses become silent instead of loud (P3)

The removed branch did `param = params_dict[scale_name]`, so a name the model didn't own raised `KeyError` at load time. Post-change, a mapped kv-scale name falls into the `else` at `:1184` and hits `if name not in params_dict: continue` (`:1193`) — the weight is dropped with no log and no error, and the model serves with an uninitialised scale.

This matters here specifically because of the pre-existing line at `:1162-1163`:

```python
if name.startswith("model."):
    name = "model." + name
```

which turns `model.…` into `model.model.…` (it reads like an inverted `if not name.startswith(...)`). Any checkpoint whose kv-scale names carry the `model.` prefix now silently loses them. The prefix line is pre-existing and out of scope for this PR, but the *silent* failure mode is new. Minimum change: log a warning (or add to a `skipped` set) when a `*_scale` name is not found in `params_dict`, rather than a bare `continue`. `mammoth_moda2` does not have this problem — its `else` branch still does `params_dict[name]` at `:526` and stays fail-loud.

### 5. `mammoth_moda2.py:488` and `mimo_audio_llm.py:1158` — dead guard (nit)

```python
if cache_scale_mapper is not None:
```

`get_cache_scale_mapper()` is a `@staticmethod` on `QuantizationConfig` that unconditionally constructs and returns a `WeightsMapper` (`base_config.py:194-227`). The guard can never be false. Collapse to `weights = self.quant_config.get_cache_scale_mapper().apply(weights)`.
