# Pre-registration — wave-5 pooled measurement (v16 vs CC+Opus 5)

Written and committed BEFORE the wave-5 arm or baseline was generated, and
before any wave-5 verdict existed. Its purpose is to fix the analysis so the
result cannot be chosen after seeing the data — the failure mode this campaign
has already committed once (raw-mean "precision above baseline", withdrawn
after the paired analysis contradicted it).

## Question

Wave 4 answered at n=10 items and could not resolve the differences under
study: pooled Δrecall −.070 [−.161, +.021], Δprecision +.015 [−.025, +.055],
both spanning zero, at an item-level sd of .127. **Is the v16 arm's recall
genuinely below the CC+Opus 5 baseline, or is the observed −.07 point estimate
noise?** Precision is the secondary question, same test.

## Design (fixed here)

* **Arm**: `v16` exactly as committed at d5d6193/893d745 — DS v4-pro core,
  Fable-5 in the adversary and second-round seats via the claude-code backend,
  planner+promotion on v4-flash. No pipeline edits between this document and
  the measurement; if any are made, this pre-registration is void and must be
  re-issued.
* **Baseline**: `baselines/claudecode_opus5`, generated by
  `run_baseline_pinned.py holdout5` under the same pinned-worktree/frozen-
  snapshot protocol as every other split.
* **Items**: wave 5 (`holdout5`) = 5676, 5732, 5752, 5871, 5946, 5983, 5991,
  6023, 6070, 6075 — the seeded stratified draw in
  `provenance_wave5.json`, frozen before generation. Pooled with wave 4
  (`holdout4`, 10 items) for the primary analysis: **20 fresh items**.
* **Judge**: claude-sonnet-5 via `judge_val.py`, 3 replicates per item, blind
  pairwise, same protocol as every other row.
* **Analysis**: `paired_analysis.py --pool goal_v16f_holdout4_sonnet
  goal_v16f_holdout5_sonnet`. Primary statistic = Δrecall (arm − baseline),
  paired within each verdict, replicates averaged per item, two-sided 95% t-CI
  over the 20 items. Secondary = Δprecision, same construction.

## Decision rule (fixed here)

Let CI be the 95% interval for pooled Δrecall over 20 items:

* **CI entirely below 0** → the recall deficit is real; report it as measured
  and stop claiming parity.
* **CI entirely above 0** → the arm's recall exceeds the baseline.
* **CI contains 0** → parity within measurement precision at n=20; report the
  interval as the bound achieved and do NOT run a third wave hunting a
  favorable draw. State the residual uncertainty as the result.

The same rule applies to Δprecision. A per-item breakdown is reported either
way, because wave 4 showed the aggregate is carried by a minority of items and
that structure is more actionable than the mean.

  item exclusion after seeing verdicts, no post-hoc re-weighting.
* pr5871 ("[Misc] Add vLLM-Omni PR review skill") is in the draw and is KEPT:
  removing an item after seeing what it is would be exactly the selection bias

  never silently dropped from the denominator.
