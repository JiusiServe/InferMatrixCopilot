# skill-omni-creation 网页抓取到统一 Stage01 Blocks（scrape_page）

<!-- kb:knowledge owner=feature-skill-page-scrape-blocks facet=features pin=f0a69728c96b5961d993449f1a901cbd2f4dac5b verdict=pass -->

**支持的抓取行为与依赖关系**

支持：无头 Chromium 单页抓取（stealth UA、可选 playwright_stealth、cookie 横幅点掉、懒加载滚动）；统一 blocks 提取，覆盖语义标签、ARIA 角色、contenteditable/自定义编辑器、canvas、JS 渲染的 div/section/article 叶子文本，并对嵌入的 YouTube/Bilibili/Vimeo 链接做 `detect_video_urls_from_html` 归一；平台 URL 走 yt-dlp/Bilibili API 取标题后直接移交流程。外部依赖包括 Playwright+Chromium（由 environment_gate 自动修复安装）、bs4、yt-dlp 子进程和 stage_04b 视频处理、download_images 的 stage02 消费方。文档证据缺失，以上仅来自所示实现。

**命令行入口与退出契约**

scrape_page.py 以 `main()` 为入口，接受可选位置参数 url、slug，以及 `--out`（覆盖默认的 work/<slug>/stage01.json 输出路径）和 `--check-deps`。环境门失败时退出码为 2；仅当异常从 `scrape_page()` 逃逸（如浏览器启动失败）才以退出码 4 结束，而单页加载异常在 `scrape_one_page` 内被捕获并返回空 HTML 继续。写入由 common.write_json 原子完成（tmp 文件加 os.replace）。

**阶段数据流：stage01 块到下游消费**

scrape_page 用 Playwright 抓单页，将 DOM 解析为统一 blocks（heading/text/image）并写入有界的 stage01.json。download_images（stage02）读取整个 stage01：仅对 image 块并发下载与去重，但所有非 image 块原样保留并连同资产清单一起写入 stage02.json。print_blocks 为 stage01/02/03 提供同一套有界代表视图（`_select_bounded_indices` + 字符预算），避免下游扩大模型可见上下文。

**依赖门与 --check-deps 自检**

两个脚本都提供 `--check-deps`：只运行共享环境门（自动修复后退出），成功打印 DEPENDENCIES_OK，EnvironmentGateError 时退出码 2。Chromium 启动校验仅在 web/web-images profile 下执行——scrape_page 的 `--check-deps` 走 require_web=True 的 web profile，会验证/修复 Chromium；download_images 使用 images profile（仅 requests/Pillow），不做 Chromium 校验。

**Stage01 有界输出的常量与环境门配置**

Stage01 的体量由 scrape_page.py 顶部的模块常量控制：STAGE01_MAX_BLOCKS=420、STAGE01_MAX_TOTAL_TEXT_CHARS=60_000、STAGE01_MAX_PAGE_OUTPUT_CHARS=90_000；STAGE01_MIN_TEXT_ALLOCATION=40 是加权水填充分配的基准下限参数，实际分配会被预算和原文长度截断（base = min(floor, budget//len)），并非每个保留文本块保证拿到 40 字符。另有按 format 的结构化文本上限（code/editor 4000、table 2500、definition 2000、canvas 2000、js_text 1200）。运行环境由 environment_gate 的 profile 决定（requests/images/web/web-images），解释器选择顺序为：激活的 VIRTUAL_ENV、已存在的项目 .venv、当前 venv，之后才可能自动创建项目 .venv；web/web-images profile 额外校验并自动修复 Playwright Chromium。
