# 插桩计划生成器（调用图深度受限展开）：实现深读

[功能概览](feature-ascend-trace-instrumentation-planner.md) · [owner 入口](_index.md)

<!-- kb:depth feature=ascend-trace-instrumentation-planner facet=api pin=f0a69728c96b5961d993449f1a901cbd2f4dac5b sha256=fb2d02ce49673576d6337c1548c4a8c02ebc4d0f36a7ba71cfbc2374294c9dc8 -->
**命令行接口：--root 与 --entry 必填，-o/--output 默认 instrumentation_plan.json**
脚本是独立 CLI（argparse）：--root 指定算子源码根目录、--entry 指定入口函数名，二者 required；-o/--output 默认 "instrumentation_plan.json"。成功时写出缩进 2 的 JSON，顶层键为 root（解析后的绝对路径字符串）、entry、max_depth（固定 5）、plan；入口不存在时以非零方式 SystemExit 并输出 "entry function not found: {entry}"。调用方需保证 root 是可读目录。

**展开深度由常量 MAX_DEPTH=5 固定，无命令行覆盖项**
深度上限是模块级常量 MAX_DEPTH = 5，输出 JSON 的 max_depth 字段记录该值；CLI 未提供调整参数。子节点 depth 记为 min(depth+1, MAX_DEPTH)，当 depth+1 > MAX_DEPTH 时子节点标记 merged=True、merge_reason="depth_limit" 且不再入队。

**入口缺失即 SystemExit；未闭合函数体回退为剩余文本**
触发一：args.entry 不在扫描到的函数名集合时 raise SystemExit(f"entry function not found: {args.entry}")，进程终止、不写输出文件。触发二：extract_block 扫描到文本末尾仍未配平花括号时返回从开括号到文件末尾的剩余文本（含 n-1 结束索引），即解析容错而非报错。循环边由 seen_edges 的 (fn, c, depth) 三元组去重防止重复展开。
