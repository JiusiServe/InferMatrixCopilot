# 插桩编译安全静态检查器：实现深读

[功能概览](feature-ascend-trace-compile-safety-checker.md) · [owner 入口](_index.md)

<!-- kb:depth feature=ascend-trace-compile-safety-checker facet=flow pin=f0a69728c96b5961d993449f1a901cbd2f4dac5b sha256=e62b7c5db497ba44908da24650cd2a0f7a7c96a32017142d74fee7cda66f5813 -->
**main() 遍历算子目录下 .cpp/.h/.hpp（排除 build_out/pregen）并逐项运行检查**
main() 对 operator_dir 执行 rglob 收集 .cpp/.h/.hpp，过滤含 build_out 或 pregen 的路径，对每个文件跑 brace/preprocessor/trace-point/scope/profiling 检查，再对 op_kernel 文件做 header 可达性与 kernel 输出一致性检查，最后输出 warnings/errors 并在通过时打印 PASSED。单个 brace 检查内部发现 depth<0 时记录一条 error 后 return，仅跳过该文件剩余行，不影响其他文件。

**CLI 契约：位置参数 operator_dir 与可选 --strict，失败时 sys.exit(1)**
main() 通过 argparse 接受位置参数 operator_dir（应含 op_kernel/ 与 op_host/ 的算子根目录）和可选 --strict；当存在 error，或 --strict 且有 warning 时，记 FAILED 并在 main 内调用 sys.exit(1)，否则输出 PASSED 汇总日志。

**括号 depth<0 或文件末尾 depth≠0 各记一条 ERROR 并可定位到行号**
check_brace_balance 在剥离注释/字符串后统计深度：depth<0 时 error("brace depth went negative ... likely extra '}'") 并 return；遍历完 depth!=0 时在最后一行报 "brace imbalance: depth=N at end of file (expected 0)"。这些 error 使 result.ok 为 False，main 打印 FAILED 并 sys.exit(1)。CheckResult.ok 定义为 errors 列表为空。
