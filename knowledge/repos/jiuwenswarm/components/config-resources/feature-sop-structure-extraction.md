# SOP 结构化抽取（parse_sop_raw_text / parse_sop_file）

<!-- kb:knowledge owner=feature-sop-structure-extraction facet=api pin=f0a69728c96b5961d993449f1a901cbd2f4dac5b verdict=pass -->

**公开入口与契约**

包级导出（`skill_gen/__init__.py`）暴露 `parse_sop_file`、`parse_sop_raw_text`、`DEFAULT_SINGLE_SHOT_BUDGET` 及模型和 fallback 工厂。`parse_sop_raw_text(raw_text, *, invoke_llm_json, parse_options=None, source_label="")` 是核心异步入口，必须传入 `invoke_llm_json`（完整 SOPStructure 抽取仅靠 LLM），返回 `(SOPStructure, extraction_meta)`，全文始终写入 `SOPStructure.raw_text`。`parse_sop_file(file_path, ...)` 先检查文件存在（缺失抛 `FileNotFoundError`），空文本/空抽取抛 `ValueError`。

**分层抽取流程与模式选择**

入口层 `parse_sop_raw_text` 校验非空文本后，按 `sop_parse_mode` 决定路径：`chunked`/`single` 直接切换，`auto` 则在「应用正的 `single_shot_budget` 上限之后的 `room_single`」与原文长度比较，超出才走分块（sop_parser.py:L275–L293）。分块路径由 `extract_structure_chunked` 做 map-reduce：按预算递归二分切块、逐块 LLM 抽取、确定性合并，多块时再跑可选 reconcile LLM 整理；单发路径 `extract_structure_single_shot` 只做一次 LLM 调用。若分块结果出现 ≥2 条空块警告，会截断原文（仅在超预算时）跑一次单发兜底，且仅当单发结果的 steps+knowledge_items+sections 计分不低于分块结果时才替换，并在 meta 标记 `replaced_by_single_shot_after_chunk_loss`（sop_parser.py:L315–L337）。

**解析选项与字符预算**

`parse_options` 由 `_default_parse_options` 填充默认值：`sop_parse_mode="auto"`、`single_shot_budget=12000`、`max_chunk_chars=8000`、`chunk_overlap=1200`、`max_context_chars=120000`、`safety_margin=2000`。单发可用空间 `room_single = max(1, max_context_chars - 模板开销 - safety_margin)`，且仅当 `single_shot_budget` 为正并小于该值时进一步收紧。分块路径把非正的 `max_chunk_chars` 以 `None` 传入 `extract_structure_chunked`，`_compute_room_for_chunk` 仅在 `max_chunk_chars` 为正时用它截小房间，最终下限为 1。

**分块合并与单发兜底的取舍**

分块路径用 `merge_partial_dicts` 做确定性合并（按 step_number 去重合并、按 id 合并 sections、多数投票 sop_type，分歧时判 hybrid），多块时可用 `_RECONCILE_PROMPT` 整体替换合并稿。当 ≥2 个分块抽取为空时触发单发兜底，但替换判据仅是 steps+knowledge_items+sections 的数量总和 `score_s >= score_c`（sop_parser.py:L329–L333）——这是数量启发式，不保证单发结果质量不低于分块结果；且截断警告仅在单发被采纳时才追加（L337–L341），兜底单发本身的截断在其他路径下不记录。

**运行时自检：空抽取与弱结果信号**

两条路径都在抽取完全为空（无 steps、无 title、无 knowledge_items）时追加 `extraction_empty_after_chunked` / `extraction_empty_single_shot` 警告并抛 `ValueError`，异常消息携带 `merge_warnings`。空抽取检查之后，`weak_reasons` 仅在分块且 `chunk_count > 1` 时由四类质量信号推导：缺 title、sections ≥3 却缺 scope、长文（超过 room_single）但 knowledge_items < 3、以及未应用 reconcile；命中任一即置 `use_raw_excerpt_draft_fallback = True`。`extraction_meta.output_counts` 记录五类输出条数。
