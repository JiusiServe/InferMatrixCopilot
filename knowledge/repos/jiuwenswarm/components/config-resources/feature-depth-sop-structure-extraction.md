**auto 模式按 room_single 判定分块，否则单次抽取并记录弱抽取原因**
mode 为 auto 时仅当 len(raw_text) > room_single 才走 extract_structure_chunked（run_reconcile=True），否则截断到 room_single 走单次抽取；随后计算 weak_reasons，置 sop.raw_text=raw_text 并返回 (sop, extraction_meta)。

**parse_sop_file 为异步入口，调用方必须以关键字传入 invoke_llm_json，返回 (SOPStructure, extraction_meta) 且全文存入 raw_text**
parse_sop_file(file_path, *, invoke_llm_json, parse_options=None) 是 async 函数，invoke_llm_json 为必需的关键字参数，返回 (SOPStructure, extraction_meta)；文档字符串声明完整文档文本始终写入 SOPStructure.raw_text。单发路径中若 LLM 抽取后 steps、title、knowledge_items 均为空，则追加 merge_warning "extraction_empty_single_shot" 并抛 ValueError。底层 extract_structure_single_shot 收到的是（可能截断的）原文文本而非完整 prompt，prompt 在其内部由模板构造；invoke_llm_json 带 fallback={} 与 trace_tag="sop_extract_single_shot"，若返回非 dict 或为空，helper 本地记录 "empty_llm_response" 并返回空 SOPStructure 与 meta，不在此层抛错。

**默认字符预算常量与 auto 模式：仅当 len(raw_text) > room_single 时走分块路径**
默认值由常量定义：`DEFAULT_SINGLE_SHOT_BUDGET = 12000`、`DEFAULT_MAX_CHUNK_CHARS = 8000`、`DEFAULT_CHUNK_OVERLAP = 1200`、`DEFAULT_MAX_CONTEXT_CHARS = 120_000`、`DEFAULT_SAFETY_MARGIN = 2000`。模式为 `auto`（else 分支）时，仅当 `len(raw_text) > room_single` 才置 `use_chunked` 并调用 `extract_structure_chunked`（非正的 `max_chunk` 以 `None` 传入）；分块房间在 `_compute_room_for_chunk` 中仅当 `max_chunk_chars > 0` 且 `room > max_chunk_chars` 时收紧，下限 `max(1, room)`。

**空抽取（无 steps/title/knowledge_items）在单发与分块路径均记入 merge_warnings 并抛 ValueError**
分块路径：若 `not sop.steps and not sop.title and not sop.knowledge_items`，先 append `"extraction_empty_after_chunked"` 到 `merge_warnings` 再 `raise ValueError`；单发路径同样 append `"extraction_empty_single_shot"` 后抛错。单发前若 `len(raw_text) > room_single` 会截断提示词并记 `single_shot_prompt_truncated_to_{room_single}_chars` 警告；更底层地，`extract_structure_single_shot` 在 LLM 返回非 dict 或空 dict 时记 `"empty_llm_response"` 并返回空 `SOPStructure()`（该空结构随后触发上层 ValueError）。
